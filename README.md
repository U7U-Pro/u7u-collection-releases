# U7U Collection

U7U Collection installs and updates the U7U plugins. Windows 10 or 11, 64-bit.

## Install

1. Download [U7U-Collection-Setup.exe](https://github.com/U7U-Pro/u7u-collection-releases/releases/latest/download/U7U-Collection-Setup.exe).
2. Run it. The installer isn't signed yet, so Windows may show "Windows protected your PC": click **More info**,
   then **Run anyway**.
3. Open U7U Collection and click **Install** on the plugins you want.
4. Rescan plugins in your DAW. In FL Studio: Options › Manage plugins › Find plugins.

Plugins install to `C:\Program Files\Common Files\VST3`. To use another folder, open settings (the gear) and click
**Change…**. Windows asks for permission when the folder needs it.

## Updates

The store checks for updates when it opens and every 30 minutes while it's open. Plugins with a new version show
**Update**, and the button at the top updates them all at once.

## Without the store

Every [release](https://github.com/U7U-Pro/u7u-collection-releases/releases) also has each plugin as a zip. Unzip
it into your VST3 folder.
